# 01 带货脚本模板

脚本怎么写：带货口播脚本 prompt、AI UGC 视频模板，拿来就能改着用。

| 项目 | 一句话（解决什么/适合谁） | 核心用法 | 安装 | 怎么用它搞钱 | 来源 |
|---|---|---|---|---|---|
| Seedance / 即梦带货脚本模板 | 给带货短视频写口播脚本的 prompt 模板，适合刚起步的带货博主和想接脚本单的人 | 1. 填入产品卖点和目标人群 2. 选脚本结构（痛点种草 / 测评 / 剧情） 3. 生成口播文案 4. 按脚本拍摄或生成画面 | 无安装，复制 prompt 模板直接用 | 脚本代写单：一条带货脚本 50–200 元起，熟练后可批量接 | X 实战帖 / 文案库条目（来源：@Seedance 相关实战） |
| AI UGC 视频 TikTok / Reels 带货模板 | AI 生成 UGC 风格带货视频的模板流程，适合做跨境带货、想批量起号的人 | 1. 选品并准备产品素材 2. 套用 UGC 模板生成口播 / 测评视频 3. 一次批量出多条 4. 挂 TikTok Shop / Reels 发布 | 无安装，复制模板流程直接用 | 跨境带货账号代运营：账号起号后按月收代运营费 | X 实战帖 / 文案库条目（AI UGC 带货模板） |
