## 报价单模板（示例）

| 档位 | 内容 | 价格（示例） |
|---|---|---|
| 体验档 | 10 条带货短视频 / 月，脚本 + 成片 | ¥2,000 / 月 |
| 标准档 | 30 条 / 月，脚本 + 成片 + 发布代运营 | ¥5,000 / 月 |
| 定制档 | 脚本 + 成片 + 投流素材 + 数据复盘 | 面议 |

## 接单话术（要点）

1. 先问对方类目和目标（带货 / 引流 / 品牌），不问直接报价
2. 报案例不报过程：发 3 条同类目成片，对方要的是结果
3. 报价只报三档，不给单条散卖（散卖压价）
4. 交付 checklist：脚本确认 → 成片 → 修改 1 次 → 发布，写进合同
