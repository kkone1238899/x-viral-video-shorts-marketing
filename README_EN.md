# AI Short-Video Marketing Playbook

**Who it's for**: people who want to make money with AI-generated marketing / e-commerce short videos — running accounts, selling editing services, or doing done-for-you operations.
**What it solves**: how to write selling scripts, how to build an AI video pipeline, how to price client work — a hands-on playbook, not a link dump.
**Value prop**: every entry carries a "how to monetize it" note. Only things that fit into a real workflow get in.
